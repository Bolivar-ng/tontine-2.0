## Notes méthodologiques (à lire avant de se fier aux comptes)

- **Colonne « Corrigés — Guide (p.) »** : pages dans `CIAM_TleSM_Corrections_Exercices.pdf` où se trouve le corrigé du chapitre.
- **Colonne « Manuel élève (p.) »** : plage de pages du manuel telle qu'annoncée en tête de chaque chapitre du Guide. Pour le chapitre 1, la plage exacte n'est pas imprimée dans le Guide → estimée (≈ 5–32) d'après les exercices cités.
- **Colonne « Exercices corrigés (≈) »** : nombre d'en-têtes « ♦ Exercice … p. … » détectés automatiquement dans la couche texte (OCR) du Guide.
  - Une **sous-question corrigée séparément** (ex. *Exercice 1.a*, *1.b*, …) compte comme **une entrée**. Le chiffre reflète donc le nombre de **corrigés distincts**, pas le nombre d'énoncés du manuel.
  - Certains numéros manquent (ex. dans le ch. 1 : 60, 67, 69, 77, 78, 81) : ces exercices **ne sont pas corrigés** dans le Guide.
  - Comptage **approximatif** : l'OCR du Guide comporte du bruit → écart possible de quelques unités par chapitre. À vérifier ponctuellement sur le PDF.
- **Le manuel de l'élève est un scan sans couche texte** : les renvois de pages proviennent uniquement du Guide, non d'une lecture directe du manuel.
